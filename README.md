
# Newzify

Newzify is a simple news reading app built in Kotlin for Android.  
It helps users stay updated with the latest headlines and read stories in one place.

## Features

- 📢 **Latest Headlines** – Get fresh news updates.  
- 🏅 **Categories** – Browse sports, tech, business, entertainment, and more.  
- 📰 **Article Preview** – Each story shows title, image, and a short description.  
- 📖 **Full Article View** – Tap any news to read the complete article inside the app (WebView).  
- ⭐ **Bookmarks** – Save articles to read later, even without internet.  
- ⚙️ **Preferences** – App remembers your theme (dark/light) and language choice.  

## How it Works

1. Open the app → see the latest headlines.  
2. Select a category → filter news by topic.  
3. Tap an article → read it fully inside the app.  
4. Bookmark articles → read them later offline.  
5. Set preferences → choose dark/light theme and language.  

## Tech (Under the Hood)

- **Language**: Kotlin  
- **Architecture**: MVVM + Repository  
- **UI**: Jetpack Compose (or XML)  
- **Networking**: Retrofit + Coroutines  
- **Local Storage**: Room Database (for bookmarks)  
- **Dependency Injection**: Hilt  

## In Short

👉 Newzify lets users **stay updated with current news**, **read details easily**, and **save favorite stories for later**.
